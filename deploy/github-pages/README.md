# starsagitarian.github.io

Sends visitors on to [starsagitarian.vercel.app](https://starsagitarian.vercel.app), keeping the
page they asked for (`/projects` goes to `/projects`). `404.html` is the same page, so every
address redirects; `.nojekyll` serves the files as they are.

The source lives in the portfolio repository, in `deploy/github-pages`.
